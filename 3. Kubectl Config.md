## Kubectl

Kubectl varsayılan olarak /home/../kube/config isimli dosyaya bakar. Bu dosya içinde cluster'ın API Server bağlantı linki, user bilgisi gibi şeyler bulunur.

Config dosyası içinde context diye bir kısım var bu kısımda cluster'a hangi user ile bağlanıcağımız ve hangi namespace'e erişeceğimizi görebiliriz. Örneğin 5 context varsa bu şu demek oluyor, ben 5 farklı kubernetes cluster'a bağlanabilirim.

```kubectl config``` komutu ile kullanılabilecek subcommentleri görebiliriz.

```kubectl config get-context``` komutu mevcut contextleri gösterir, birden fazla context olduğu durumda yanında * olan context kullanılan context'dir.

```kubectl config current-context``` komutu ile kullanılan context'i görebiliriz.

```kubextl config use-context <kullanılması istenilen context>``` belirtilen context ile çalışmasını sağlar.

```kubectl cluster info``` üzerinde çalıştığımız kubernetes cluster ile ilgili bilgi almak için kullanılır.

```kubectl <komut> --help``` belirtilen komutun nasıl çalıştığını görebiliriz.

```kubectl <yapmak istediğimiz işlem (delete)> <obje tipi (pod)> <objenin ismi (testpod)>``` Örnek komut tipi

Kube komutu aksi belirtilmediği sürece tüm komutlar context set edilmiş namespace üzerinde uygulanır, context'de namespace belirtilmemişse default isimli namespace kullanılır.

```kubectl get pods -n <namespace ismi>``` komut belirtilen namespace'in üzerinde çalışır

```kubectl get pods --all-namespaces``` tüm namespace'lerde çalışır.

```kubectl get pods -A -o wide``` daha detaylı bir output almamızı sağlar

```kubectl get pods -A -o yaml/json/jsonpath/go-template/custom-columns``` yaml/json/jsonpath/go-template/custom-columns formatında çıktı görmemizi sağlar.

```kubectl get pods -A -o json | jq -r ".item[].spec[].container[].name"``` Sadece isimleri gösterir, özelleştirilmiş bir komuttur.

```kubectl explain <obje ismi (pod)>``` belirtilen obje hakkında bilgi verir (örneğin pod objesi hakkında bilgi verir).
