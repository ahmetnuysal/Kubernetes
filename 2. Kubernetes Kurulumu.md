## Kubernetes Kurulumu

1. Öğrenme, test etme ve geliştirme için kendi PC'mize kurmak için "Minikube" veya "Docker Desktop" kullanılabilir.
2. Birkaç sanal makineye veya fiziksel makineye tam bir kubernetes cluster kurulumu için "Kubeadm", "k0s", "RKT", veya "Kubespray" vb kullanılabilir.
3. Public cloud için "Azure Kubernetes Service (AKS)", "Google Kubernetes Engine", "Amazon EKS" kullanılabilir.

NOT: Bu dökümanlarda "Minikube" kullanılmıştır.

### 1.Minikube Kurulumu

Minikube kubernetes cluster oluşturmak için kullanılır.
 
Kendi PC'mizde single node bir cluster kurmamızı sağlıyor.

Load balancer servisi add on ile simule edilebilir.

Tek bir komut ile cluster kapatıp açabiliriz.

Minikube kurduktan sonra sistemde herhangi bir sanallaştırma katmanı (Docker, Hyperkit, Hyper-V, Podman, VirtualBox, VmWare) var mı diye bakar. 

Öncelikle bir sanallaştırma katmanı kurmak gerekiyor. (https://virtualbox.org)

**Debian**: Ubuntu tabanlı

**RPM**: Redhat tabanlı

> 1. MacOs veya Brew yüklü Linux Minikube kurulumu

1. ```brew install minikube``` komutu ile kurulumu yapıyoruz.
2. Eğer fail verirse ```brew unlink minikube``` ardından ```brew install minikube``` komutunu çalıştırıyoruz.

> Windows için Minikube kurulumu

1. .exe ile yüklenebilir.
2. ```winget install minikube``` komutu ile yüklenebilir.
3. ```choco install minikube``` komutu ile yüklenebilir.

### 2. Minikube Kullanımı

- minikube start: Cluster oluşturmak ve kubectl ile konuşturmak için kullanılır. Durdurulmuş cluster'ı tekrardan başlatmayı sağlar.
- minikube start --driver=<sanallaştırma adı>: Docker, Virtual Box, Hyper-v Kullanarak cluster oluşturmamızı sağlar.
- minikube status: Kontrol etmemizi sağlar.
- minikube get nodes: Node'ları kontrol etmemizi sağlar.
- minikube delete: Cluster'ı siler.
- minikube stop: Cluster'ı dururur.
