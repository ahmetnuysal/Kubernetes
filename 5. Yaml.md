## 📄 Örnek YAML Şablonu (`objectbasetemplate.yaml`)

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: firstpod
  labels:
    app: front-end # Bu objeye atanacak etiketleri tanımlıyoruz
spec:
  containers:
    - name: nginx
      image: nginx:latest
      ports:
        - containerPort: 80
```

## 🔍 YAML Alanlarının Açıklamaları

* **`apiVersion`:** Kubernetes üzerinde objenin hangi API sürümünü kullanacağını belirtir.
  > 💡 **İpucu:** Hangi objenin hangi API versiyonunu kullanacağını öğrenmek için `kubectl explain pods` komutunu çalıştırabilirsiniz.

* **`kind`:** Oluşturulmak istenen Kubernetes objesinin türünü belirtir *(Örn: Pod, Deployment, Service)*.

* **`metadata`:** Obje ile ilgili tanımlayıcı bilgilerin *(meta-data)* yer aldığı kısımdır.
  * **`name`:** Objeye verilecek benzersiz isim *(Örn: `firstpod`)*.
  * **`labels`:** Objeye atanacak özel etiketler/anahtar-değer *(key-value)* çiftleridir.

* **`spec`:** Objenin sahip olacağı konfigürasyon detaylarını içerir *(Konteynerlar, imajlar, portlar, vb.)*.
  > 📝 **Not:** `spec` alanı objelerin çoğunda bulunur; fakat bazı obje tiplerinde bulunmayabilir veya yapısı farklılık gösterebilir.
