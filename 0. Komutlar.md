1. Kubectl get nodes: Node bilgilerini gösterir.
2. minikube start: Cluster oluşturmak ve kubectl ile konuşturmak için kullanılır. Durdurulmuş cluster'ı tekrardan başlatmayı sağlar.
3. minikube start --driver=<sanallaştırma adı>: Docker, Virtual Box, Hyper-v Kullanarak cluster oluşturmamızı sağlar.
4. minikube status: Kontrol etmemizi sağlar.
5. minikube get nodes: Node'ları kontrol etmemizi sağlar.
6. minikube delete: Cluster'ı siler.
7. minikube stop: Cluster'ı dururur.
8. kubectl config: Kullanılabilecek subcommentleri görebiliriz.
9. kubectl config get-context: mevcut contextleri gösterir, birden fazla context olduğu durumda yanında * olan context kullanılan context'dir.
10. kubectl config current-context: komutu ile kullanılan context'i görebiliriz.
11. kubectl config use-context <kullanılması istenilen context>: Belirtilen context ile çalışmasını sağlar.
12. kubectl cluster info: üzerinde çalıştığımız kubernetes cluster ile ilgili bilgi almak için kullanılır.
13. kubectl <komut> --help: Belirtilen komutun nasıl çalıştığını görebiliriz.
14. kubectl <yapmak istediğimiz işlem (delete)> <obje tipi (pod)> <objenin ismi (testpod)>: Örnek komut tipi
15. kubectl get pods -n <namespace ismi>: komut belirtilen namespace'in üzerinde çalışır
16. kubectl get pods --all-namespaces: tüm namespace'lerde çalışır.
17. kubectl get pods -A -o wide: daha detaylı bir output almamızı sağlar
18. kubectl get pods -A -o yaml/json/jsonpath/go-template/custom-columns: yaml/json/jsonpath/go-template/custom-columns formatında çıktı görmemizi sağlar.
19. kubectl get pods -A -o json | jq -r ".item[].spec[].container[].name": Sadece isimleri gösterir, özelleştirilmiş bir komuttur.
20. kubectl explain <obje ismi (pod)>: belirtilen obje hakkında bilgi verir (örneğin pod objesi hakkında bilgi verir).
21. kubectl api-resources --verbs=list --namespaced -o name | xargs -n 1 microk8s kubectl get --show-kind --ignore-not-found -n bck: Bir namespace'deki tüm kaynakları listeler.
